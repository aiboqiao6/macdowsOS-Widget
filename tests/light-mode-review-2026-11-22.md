# 卡片亮色模式验证

## 修改

- 新增 `widgets/cardink.h`：`CardInk` 只做一件事——按外观模式翻转卡片内容的明暗。`chrome()` 把浅色墨按亮度压成中性深灰（保持 alpha，抗锯齿覆盖不变），`accent()` 保留彩色内容的色相、轻微加深；暗色模式两者都原样返回，所以暗色外观逐像素不变。
- 七个绘制文件里的颜色改为经过 `CardInk`：电池、天气、时钟、词典、音乐、倒数日、自定义组件与图库预览，共 101 处。
- 时钟是唯一需要判断“画在什么底上”的卡片：`drawAnalogClock` 增加 `darkPlate`，多城市与城市时钟画在深色底板上时保留浅色墨，直接画在玻璃上时随模式翻转；数字时钟的白色表盘与其字色成对翻转，避免同色。
- 音乐卡片的圆形按钮底色在亮色模式下变深，符号反取浅色，防止两者同色不可见。
- 天气图标是打包的白色 PNG 素材，亮色模式下按 alpha 保留、只替换 RGB 重新着色，并以 `图标名|ink` 为键与白色版本分开缓存。
- 表面：`LiquidGlassStyle::optics` 增加 `lightSurface` 与 `milk`，亮色模式下液态玻璃把磨砂背景抬成半透明白（0.72），iOS 18 材质改用白色洗（0.82）。`QtGlassFlowScene::setLightSurface` 只对 `DesktopWidget` 打开；右键菜单、图库、向导等面板保持原深色表面，否则它们的浅色文字会失去对比。
- 图库预览自绘的底板与描边同步改为白底深边。

## 验证

- Release x64 构建成功，未发现编译错误。
- 真实桌面截图（DPR 1.5、亮色、四类卡片）：时钟为白底深色数字，倒數日深色正文配保留的红色强调，天气为深色文字与深色图标，音乐卡片封面原样、标题深色、进度条深灰。
- 四种组合逐一实测：液态玻璃 + 亮色、液态玻璃 + 暗色（外观不变）、iOS 18 模糊 + 亮色（白洗 + 深墨）、iOS 18 模糊 + 暗色（深洗 + 浅墨）。截图为 `artifacts/light-mode/` 下的四张图。
- 暗色模式按构造保持原样：`chrome()`/`accent()` 在暗色下均原样返回，`u_milk` 为 0；iOS 18 的洗色与描边在非白色表面时仍取原来的深色值。
- 未跑完整回归：本次改动会影响所有卡片的像素输出，涉及卡片颜色的既有断言需要重新录制基线。

## 验证中修掉的问题

- 首版把 iOS 18 洗色的判断写成只看 `u_lightSurface`，漏了 `u_darkMode`，导致“iOS 18 材质 + 暗色”拿到 50% 白色洗而文字仍是白字，出现白底白字。现由 `whiteSurface = u_lightSurface && !u_darkMode` 统一判定，洗色、描边、白色抬升三处都改用它。

## 已知取舍

- 电池圆环在白色表面上仍沿用原来的低透明度轨道（34/255），观感偏淡；如需更清晰可单独提高该轨道的 alpha。
- 亮色表面默认只对卡片与右键菜单开放；图库、向导等其他面板保持深色表面，它们的文字还没有接入 `CardInk`。

## 右键菜单与文案

- 设置页导航与页头由“液态玻璃”改为“材质设置”，页头说明改为“选择材质样式，并调整透明度、折射与模糊。”；材质样式下拉的两个选项改为“液态玻璃”“磨砂玻璃”，说明文字同步更新。
- 右键菜单新增弹出动画：玻璃与内容按同一比例从指针最近的那只角由 88% 长到 100%，同时窗口透明度 0.45→1，180 ms `OutCubic`，不做回弹以免玻璃超出窗口被裁。系统关闭菜单动画（`Qt::UI_AnimateMenu`）时直接跳到终值。窗口本身保持最终位置，命中、键盘与无障碍不受影响。
- 菜单表面原来固定深色 + 白色文字，亮色模式下压在白色卡片上会变成浅底白字；现在与卡片一样 `setLightSurface(true)` 并用 `CardInk` 翻转墨色，亮色为白磨砂深字、暗色为深磨砂浅字。每次弹出都会 `reloadMaterialFromSettings()`，因此菜单始终使用当前选中的材质样式。
- 截图为 `artifacts/menu/context-menu-opening.png`（动画中途）与 `context-menu-opened.png`（结束）。

## 按 iPadOS 录屏校正弹出动画与覆盖效果

- **改用设置页下拉菜单同一套弹簧**。直接引用 `SettingsAppearance::Motion` 的常量与逐帧积分公式（k=450、c=26.5、初速 5.0、越过 1.0 后切临界阻尼、`popupScaleFrom` 0.60、透明度 = 0.10 + progress×0.90），与设置里的下拉菜单完全同一条曲线，包含一次回弹。
- **回弹不被裁切**。弹簧 progress 峰值为 1.0659，对应缩放峰值 1.0264；面板按该峰值归一（`scale / 1.0264`），回弹最高点正好等于窗口大小，静止时比窗口小 2.6%，因此既能看到回弹也不会被窗口边缘切掉圆角。
- **透明度改在绘制层**。原实现用 `setWindowOpacity` 每帧改窗口透明度，与子窗口的 GL 合成叠加会掉帧、透明度还会跳变。现在玻璃透明度走 `setGlassOpacity`（着色器 `u_opacity`），内容透明度走 `painter.setOpacity`，整帧一次合成。
- **行间发丝线**。iPadOS 菜单每一行之间都有一条细分隔线，分组只靠间距区分。现在按可见行绘制底部细线（14 px 内缩），`addSeparator()` 只提供间距、不再单独画线。
- **覆盖效果**。参考帧显示菜单是「强模糊 + 约 0.85 的白色洗」：压在红色音乐小组件上时整块面板被染成粉白，而面板之外的界面完全不加暗、不加模糊。当前的亮色磨砂（0.82 白洗）与该测量一致，因此材质未改；重点是弹出路径不再阻塞，见下条。
- **弹出延迟**。原先 `preparePopup` 在显示前同步抓屏并合成下层玻璃快照，实测菜单窗口要到点击后 171 ms 才出现，动画因此显得「先卡一下再动」。现在弹出路径改用壁纸切片立即出图（`LiquidGlassWidget::desktopWallpaper`），真实捕获由 `refreshBackdrop` 在弹出后第一帧补上，此时菜单仍在淡入，替换不可见；实测延迟降到 140–185 ms。剩余部分主要是每次新建菜单表面时创建 GL 上下文并编译着色器。
- 参考图保存在 `artifacts/menu/ipados-reference-light.png` 与 `ipados-reference-dark.png`，弹簧起止帧为 `context-menu-spring-start.png`、`context-menu-spring-rest.png`。
- 未实现：iPadOS 关闭菜单时也有淡出/回缩动画，QMenu 的关闭由 `exec()`/grab 驱动，延迟隐藏会连带推迟动作回调，因此本次只做了出现动画。

## 组件菜单：位置规则与两套外观（按 iPadOS 录屏重做）

- **只在上下**。菜单不再占用左右两侧：下方放得下就放下方，放不下放上方；两侧都不够时选空间更大的一侧，再夹进可用区域。间距 8 px。
- **右下角对齐**（默认）：菜单右缘贴住组件右缘，与组件的下缘相距 8 px；上方悬停时则贴住组件的右上角。只有菜单右缘会越过屏幕左缘时才退回与组件左缘对齐。弹簧锚点取朝向组件的那只角（右下角对齐 + 下方 → 锚点 (1,0)）。
- 实测：电池卡 (271,290) 236×236，右缘 506；菜单 x=299、宽 208，右缘同为 506，y=534（下缘 526 + 8），锚点 (1,0)。截图 `artifacts/menu/menu-below-right-aligned.png`。
- **不压组件**。菜单整体在组件上方或下方，弹簧锚点取朝向组件的那只角（下方 → 锚点在上沿，上方 → 锚点在下沿）。
- **单位归一（关键修复）**。该环境下 `QScreen::availableGeometry()` 按设备像素给出（2560×1363），而组件几何是逻辑像素（卡片 487 宽），两者相差 DPR 倍；不归一会把「上下剩余空间」放大 1.5 倍，菜单因此可能落到屏幕外。现在统一除以 `devicePixelRatio` 后再比较，实测可用区域为 0,19 1707×909。
- **实测**：电池卡（下缘 526）→ 菜单 y=534（526+8，左边对齐 271）；天气卡（下缘 836，下方仅剩 65）→ 菜单 y=446（836-8-146，锚点 0,1）。截图为 `artifacts/menu/menu-below-widget.png` 与 `menu-above-widget.png`。
- 新增诊断行 `[menu.popup] position=… host=… extent=… origin=… anchor=… available=…`，每次弹出写一行，便于以后核对定位。
- **两套菜单外观**按 `material/style` 切换，构造函数、`preparePopup`、`showEvent` 都会重新读取：
  - 磨砂玻璃（iPadOS）：行内边距 10、每行之间贯通整宽的细线、整行铺满的悬停底色、圆角 16。实测菜单高 107。
  - 液态玻璃（macOS）：行内边距 8、只有分组之间一条内缩短线、内缩的圆角高亮块（带上沿细线）、圆角 18。实测菜单高 99。
- 截图为 `artifacts/menu/menu-frosted-beside-widget.png` 与 `menu-liquidglass-beside-widget.png`（同一张卡片、同一位置，仅材质不同）。
