# 2026-10-11 项目审查与验证

验证环境：Windows 11、Qt 6.11.1、MSVC v143、x64 Release。

## 修改范围

- 将多类型卡片宿主从 `BatteryWidget` 改为 `DesktopWidget`，拆分生命周期与放置、内容绘制、天气词典数据、设置四个实现文件；保留原有配置类型和位置兼容性。
- 删除停用的组合仪表盘、旧电量概览与重复图库内容绘制；集中参考尺寸与天气文本格式化，统一主要成员和绘图变量命名。
- 审查并改写原有注释，修正截图可见性、刷新调度、默认画质等与当前行为不符的表述；补充线程、缓存、资源释放与缩放约束说明。
- 新增 `review_comments.py`，扫描自有 C++、GLSL 与回归源码中的英文注释、英文句子及待办标记。
- 新增原生设备分辨率的 ClearType RGB 覆盖掩码与 GL 分通道混合。透明图像继续使用灰阶，背景画质不影响文字分辨率；纹理随 GL 上下文清理。
- 向导和设置复用连续缩放控件，以真实桌面尺寸显示独立栅格预览。拖动不重设全部 QSS 或改变向导 GL 表面，停止后按最终设备像素重绘。预览避让操作窗口；高 DPI 设置界面允许滚动。
- 新增紧凑与横向音乐卡片。共享后台服务读取 Windows 系统媒体会话、封面与时间线，并按系统能力启用播放控制；无状态变化时不触发重绘，空封面会重试。

## 验证结果

| 检查 | 结果 |
| --- | --- |
| 自有源码中文注释审查 | 40 个文件、405 条注释，0 项问题 |
| Visual Studio Release 构建 | 成功，无编译错误或警告 |
| 完整 Qt 回归 | 103 通过、0 失败、1 跳过 |
| 最后一次向导与媒体定向回归 | 7 通过、0 失败、0 跳过 |
| 实际 DPR 1.0、1.25、1.5、1.75、2.0 | 每档 6 通过、0 失败、0 跳过 |
| 连续缩放界面定时器 P95 间隔 | 依次为 17、31、30、31、29 毫秒 |
| Git 空白错误检查 | 通过 |

完整回归中的跳过项是 `animatedBackdropSource`，它只在独立辅助进程模式运行，正常测试进程按设计跳过；系统媒体验证没有跳过。

背景帧率测试原先比较定时器请求数与捕获帧数，未统计实际绘制。修正后记录约 59 个源窗口绘制帧、117 个定时器请求和 58 个变化背景帧，并在停止源动画后等待两个在途捕获交付；没有降低断言比例。

DPI 验证检查实际输出 DPR。此环境中 `QT_SCREEN_SCALE_FACTORS=1` 仍沿用系统 1.5，因此 100% 使用仅影响测试进程的 `QT_SCALE_FACTOR=0.6666666666666667` 校准，并确认实际 DPR 为 1.0。其余档位使用 `QT_SCREEN_SCALE_FACTORS`。

缩放延迟测试关闭桌面捕获，衡量控件与原尺寸预览的界面响应；它不是整机游戏帧率或所有背景负载下的性能保证。

媒体测试创建专用桌面 SMTC 会话，验证标题、艺术家、总时长、进度、暂停、上一首和下一首，不播放音频。真实播放器必须向 Windows 发布媒体会话，其未提供的封面、时间线或控制能力无法由组件补造。
