# 代码清理与渲染优化记录

验证日期：2026-10-11。基线为本轮清理开始时的项目工作区，包含此前完成的音乐、ClearType、向导和设置修复；不以更早版本代替基线。

## 职责与重复实现

- `desktopwidget.cpp` 从约 1800 行收敛到 267 行，保留生命周期、服务连接和设置同步。托盘、鼠标交互、放置、持久化、预览、绘制分派分别有独立文件。
- `widgets/cards` 按电量、天气、时钟、词典拆分绘制。`desktopwidget_paint.cpp` 只处理共用坐标、圆角、表面高光及类型分派，图库仍复用相同内容绘制。
- `widgets/data` 分开天气和词典的请求调度与解析；`ui/weathercitydialog.*` 只负责搜索与返回选择，配置保存及天气更新由宿主处理。
- `platform/powerdevices.*` 集中 Windows 电量、设备发现与蓝牙查询，通过调用参数限制数量，不依赖卡片布局。异步结果未变化时跳过重绘。
- `app/fontsettings.*` 统一字体注册、抗锯齿策略与显示字体构造；音乐绘制不再依赖桌面宿主的字体接口。
- `widgetgeometry.*` 统一变体和网格尺寸换算；网格占用检测复用同一入口。
- `network/cardrequest.*` 统一天气请求头、传输超时和请求总时限，回复解析仍由各数据模块管理。
- `ui/gridplacementoverlay.*` 独立处理放置提示与淡出，重复的原生置序操作合并。
- `glpixeltransfer.h` 统一字体、背景上传和快照回读的 PBO、行跨度、跳过偏移保护；字体缓存清理复用同一实现。
- 删除无调用者的屏幕拷贝函数、重复的预览初始化、电量刷新中的无效外设同步比较，以及始终禁用且无设置入口的波纹、流动、色调分支及对应 uniform 提交。

MSBuild、Visual Studio 筛选器和 qmake 清单同步覆盖新文件。原有公开宿主接口和布局配置保持兼容。

## 渲染改动

各档位的 FBO 尺寸、采样密度、高斯核权重、迭代次数、折射、噪声及边缘覆盖参数保持不变。

大高斯核按实际采样数编译固定循环程序，每个上下文缓存最多四个变体；小核沿用原程序。编译失败时回退到完整采样的原程序。连续背景帧复用已上传的核参数，水平和垂直通道共用顶点绑定、视口并直接切换 FBO。相同尺寸的背景纹理更新保留既有过滤、寻址和纹理存储。

ClearType 保留原有四通道混合。试验中的常量混合单次绘制在部分场景没有耗时收益，最终未采用。字体 RGB 覆盖率、原生像素密度及透明度计算保持原样。

## 图像与性能对照

环境：Windows 11、Qt 6.11.1、MSVC v143、Release x64、实际 DPR 1.5。固定场景为 400×310 逻辑像素，原生帧缓冲 600×465，两个模糊迭代，模糊半径 8。背景由确定性彩色图案生成，保留折射，关闭时间无关的微噪声以方便检查。

修改前后程序交替运行五轮，每轮预热十帧，采集四十八帧。每帧等待 GPU 完成，记录包含 CPU 提交与 GPU 等待的墙钟耗时。表格为五轮各自中位数、P95 的中位数；单位为毫秒。该基准不包含桌面捕获、DWM 呈现和网络，不能换算为完整应用 FPS。
