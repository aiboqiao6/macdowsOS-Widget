# 性能、延迟与占用优化

## 改动与质量约束

基线为本轮开始时的版本 `0857178`，包含统一文字渲染和音乐液态玻璃。本轮先扩展测量入口并保存 `obj/regression/release/widget_regression-before-performance.exe`，再修改生产代码，没有用更早版本代替基线。工作期间这些生产改动已由外部提交为 `b6d2cf6`；未改动同时发生的 README 精简。

- 图库稳定位置的完整 RGB32 捕获帧直接共享给背景渲染器，删除每次的整面分配、清空、绘制和 RGBA 转换。有平移、屏幕边缘缺列或透明图像时保留原有裁剪和补边路径。
- 桌面卡片捕获矩形与显示矩形一致时共享完整图像；需要局部裁剪或合成下层玻璃时继续处理原始像素，Qt 的写入时分离保护共享背景。
- 模糊从三个中间 FBO 改为两个：背景先写场景纹理，水平通道写临时纹理，垂直通道写回场景纹理。尺寸、RGBA8 格式、过滤、方向、核权重、采样数和迭代数保持一致。每个玻璃窗口减少一张 `宽×高×4` 字节的纹理，即这一组中间颜色纹理减少三分之一；这不等于整个进程显存减少三分之一。
- ClearType 纹理上传后释放每个窗口缓存的 CPU RGBA 上传副本，保留纹理、原生尺寸与偏移。全局字形缓存、字体分辨率、四通道混合保持原样。着色器链接后缓存文字 uniform 位置，减少重复查询。

没有修改画质档位、动态背景刷新节奏、模糊半径、采样密度、折射、噪声、抗锯齿或字体布局。

## 同机测量

环境为 Windows 11、Qt 6.11.1、Release x64、AMD Radeon(TM) Graphics，默认 DPR 1.5。共五轮：前三轮按旧版、新版顺序，后两轮倒序执行，不同时运行 UI 测试或编译。每个场景预热十帧，测量四十八帧。下表是五轮中位数的中位数，单位为毫秒。

图库测量的是主线程将已有捕获图像准备为显示背景的耗时，不包含 WGC、GPU 模糊、DWM 呈现或网络，因此不能当作完整应用帧时间或输入到呈现的延迟。

| 0.60 | 2.6144 | 0.0001 | 3.6718 | 0.0001 |
| 0.80 | 5.2508 | 0.0001 | 5.9227 | 0.0001 |
| 1.00 | 8.1467 | 0.0001 | 9.1265 | 0.0001 |
| 1.25 | 13.7633 | 0.0001 | 15.2849 | 0.0001 |

新路径仅做共享引用和状态更新，结果接近计时器精度；实际结论为移除了这一步毫秒级的整面像素处理，不承诺稳定的 0.1 微秒墙钟延迟。

同一固定负载末尾，五轮进程私有内存中位数为 335.19→284.25 MiB，工作集为 350.81→317.67 MiB；这是基准进程的读数，包含 Qt、驱动与分配器行为，不作为用户任意组件组合的内存承诺。该文字负载的窗口 CPU 上传副本为 514600→0 字节；全局字形缓存仍保持有界。

纯 GL 测量包含 CPU 提交及 `glFinish` 等待，分别覆盖复用缓存、重算模糊、透明文字、背景上传加模糊和文字。部分场景有所改善，部分场景及高分位数变慢，未证明所有 GPU 场景都有稳定耗时收益。本轮确认的主要收益为主线程背景准备和资源占用下降，未声称全局 FPS 按同样比例提升。

原始五轮日志为 `obj/regression/performance-before.txt`、`performance-after.txt` 及同名前缀 `-2.txt` 至 `-5.txt`。

## 像素与功能验证

五档画质 `0.6、0.8、1、1.25、1.5` × 两种亮暗模式 × 四种渲染负载，分别在 DPR `1、1.25、1.5、1.75、2` 下与本轮旧程序比较；另外比较每档图库背景。共有 225 种配置，包含重复性能轮次共 405 张最终图像比较，全部像素通道差异为零。

对比保留实际档位的确定性噪声，不改玻璃或字体参数以获得更好结果。CPU 图像与 GL 文字的原有比较继续要求最多 1 个通道值的原生后端舍入差；本轮修改前后最终图像则要求严格零差异。

原生 DPI 首轮定向检查 6 项通过，其余四档各 6 项通过（含初始化和清理），零失败、零跳过。除像素基准外还检查了透明文字、上传副本释放、图库整帧共享与屏幕边缘补齐、模糊专用程序与回退程序一致。日志为 `obj/regression/performance-after.txt`、`performance-after-dpi-*.txt`。

图像目录为 `obj/regression/artifacts/performance-before*` 和 `performance-after*`。Release 应用构建产物为 `artifacts/performance-build/macdowsOSWidget.exe`。

完整回归为 122 项通过、2 项失败、3 项按条件跳过，日志 `obj/regression/performance-full.txt`。失败的是 `foregroundNeverBecomesBackdrop(normal/topmost)`；本轮修改前保存的 EXE 和最终 EXE 各独立复测两次，均复现相同两项失败，日志 `obj/regression/performance-foreground-before-*.txt`、`performance-foreground-after-*.txt`。未放宽断言，也未把完整套件称为全部通过。

完整套件的图库动态背景检查通过：1069 毫秒内 32 个源帧、30 次采样、27 次背景变化。窗口层级、动态壁纸、移动背景、捕获重建与接收方取消、浸泡、透明边缘、上下层玻璃和原生像素字体检查通过。移动背景检查为 3001 毫秒内 180 次更新、最长间隔 18 毫秒。

另做三轮旧版→新版顺序的图库动态背景对照，新版实际变化帧数为 16、22、25，旧版为 16、20、18；新版采样为 27、30、31，旧版为 25、28、26，测量窗口约 1.05 秒。新版第一轮 27/35 的采样比例低于原有 80% 阈值，其余两轮通过。源帧数量也随界面负载变化，短时样本不足以证明固定的端到端延迟或帧率收益。日志 `obj/regression/performance-live-before-*.txt`、`performance-live-after-*.txt`。

三项正常跳过为需要额外环境配置的像素基准和参考壁纸比较，以及仅供子进程使用的动态背景源入口。像素基准已按上述矩阵独立执行。

差异格式检查通过；68 个源码文件、431 条中文注释检查零问题。应用与测试 Release 构建成功；部署工具仅提示已有的可选 D3D12 编译器和 VCINSTALLDIR 警告，当前应用使用 OpenGL。
