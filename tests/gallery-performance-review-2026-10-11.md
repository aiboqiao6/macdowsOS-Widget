# 图库布局、桌面隐藏与实时背景优化

## 修改

- 取消图库额外的 1.5 倍放大，将默认面板从 1980×1200 调整为 1170×650 逻辑像素，仍跟随全局缩放并限制在当前显示器工作区内。
- 建议区按 1×1、2×1、2×2 的真实组件比例拼排，移除卡片下方的重复标题与描述。分类继续展示其余变体，搜索覆盖全部卡片，侧栏改用彩色应用图标，完成按钮保持胶囊圆角。
- 预览继续使用 CPU 内容绘制和原生像素缓存；天气、词典、电量展示离线示例，避免空白或永久加载占位，不启动网络或外设任务。
- 隐藏普通应用窗口的生命周期从拖动卡片提升到整个图库会话。准备打开时隐藏，拖放结束时保持隐藏；完成、Esc、失焦、直接隐藏及销毁均复用恢复路径。原本隐藏或最小化的窗口不纳入恢复集合，保留桌面卡片、系统桌面宿主及任务栏。
- 静态背景模式也会在打开动画完成后补采背景，避免异步隐藏应用造成旧窗口影像残留。
- 实时背景取消由交换帧回调触发的重复绘制，捕获回调也不再无限补充请求。背景像素变化、数据变化和独立时钟动画仍主动绘制；拖动保持交互刷新。
- 变化背景维持显示器节奏的采样，最多两个请求在途。连续约 350 毫秒未变化后改为每 100 毫秒探测，检测到变化立即恢复，避免低帧率动态壁纸被少量重复帧误判为静态。

## 验证方法

- 使用修改前保留的回归 EXE 与修改后的 Release 回归程序，在同一 AMD Radeon(TM) Graphics、60 Hz 显示器环境读取背景跟随与提交帧数。
- 静态向导的旧测试要求重复提交达到显示器刷新率；现在改为检查静态时没有持续重复提交，动态测试仍检查实际背景变化帧与源帧的关系。单纯提交更多相同帧不再作为性能收益。
- 回归覆盖完整会话的原生窗口隐藏与恢复、销毁恢复、真实网格大小、搜索全部变体、缩放、原生像素预览、动态壁纸 WorkerW 宿主、图库动态背景、桌面动态背景、无变化时停止重复绘制。

最终验证结果见本文件后续记录及 `obj/regression/gallery-*.txt`。构建日志为 `artifacts/build-gallery-performance.log` 与 `obj/regression/build-gallery.log`。

## 最终验证

- 默认 `Release|x64` 应用构建成功，交付路径为 `x64/Release/macdowsOSWidget.exe`，未更改目标文件名或停止用户进程。
- 最终完整回归：110 项通过、零失败、2 项按设计跳过，耗时约 127 秒。跳过项为手动管线基准和专用动画源子进程入口。日志：`obj/regression/gallery-full-final.txt`。
- `QT_SCREEN_SCALE_FACTORS` 为 1、1.25、1.5、1.75、2 的五个独立进程分别检查原生像素预览、图库全局缩放、搜索及网格布局；每组含初始化/清理为 5 项通过、零失败。日志：`obj/regression/gallery-dpi-*.txt`。
- 原生恢复用例同时检查普通窗口、带标题的无边框窗口、原本隐藏的窗口，以及拖动结束后继续隐藏和图库销毁后恢复。
- 中文注释审查：65 个源码文件、412 条注释，零问题；差异格式检查通过。
- 已查看真实窗口截图，确认拼排比例、建议与分类分区、侧栏图标、胶囊完成按钮及原生像素预览。截图使用测试时的桌面背景，不代表用户参考图的壁纸或在线数据。

本次调度优化保留共享玻璃材质参数；没有为了提高帧率降低字体分辨率或禁用动态壁纸。
