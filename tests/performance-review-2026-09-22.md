# 2026-09-22 性能优化记录

> 2026-09-23 更新：CPU 渲染后端及其设置已移除。下文的 CPU 优化与测量是移除前的历史记录。

本轮保留现有分辨率、各档模糊核、采样数量、16 位中间精度、字形 4 倍超采样、实时刷新策略。没有通过降低画质或刷新率缩减开销。

## 改动

- CPU 模糊：把逐通道整数除法改为带纠正步骤的整数倒数乘法，在 x64/SSE2 上并行计算四个颜色通道。没有使用近似浮点平均。普通画质的纵向滤波改为连续按行访问，减少跨行读取及 Qt 缓冲区访问次数。其他平台保留标量路径。
- GPU 上传：背景方向调整移到 blit 着色器，不再在 CPU 上逐帧分配、翻转整张背景图。普通输入和预翻转输入均保留支持。
- 资源占用：CPU 模式不再创建闲置的 GPU 背景纹理；GPU→CPU 切换立即释放三张背景 FBO 和上传纹理，CPU→GPU 切换释放 CPU 模糊结果。
- 缓存：重复提交同一 QImage 时保留上传和模糊缓存；无变化的背景裁剪直接返回，省去重新构建原生窗口捕获计划的开销。发生实际合成时仍检查窗口拓扑，防止前景污染或旧图覆盖。

## 同机测量

Qt 6.11.1 / MSVC Release x64；720×400 逻辑尺寸、150% 屏幕缩放，对应原生 1080×600 背景；模糊半径设置为 8、迭代设置为 2。每档预热后连续运行 12 次，计入缩放、滤波和临时内存分配，不计入桌面捕获、窗口合成及显示等待。

| 渲染质量 | 优化前 CPU 模糊 | 优化后 CPU 模糊 | 耗时下降 |
|---|---:|---:|---:|
| 50% | 5.35 ms | 1.92 ms | 64% |
| 100% | 19.93 ms | 7.48 ms | 62% |
| 125% | 26.20 ms | 11.45 ms | 56% |
| 150% | 41.82 ms | 18.28 ms | 56% |

这是固定场景的 CPU 模糊耗时，不是端到端输入延迟，也不能直接换算成整个应用的帧率。原始记录：`obj/regression/perf-before.txt`、`obj/regression/perf-final-focused.txt`。

## 质量与正确性

- 优化前冻结了 60 组画质、半径、迭代与随机预乘透明像素输入的 SHA-256 基准，优化后保持 `9497417de83a8604b3b10fac5964f55edc64ec81b7061b4a6610d08003820c32`。测试直接比较结果，屏幕 DPI 不影响基准。
- 补充 1×1、1×7、7×1 等小图、全透明、半透明和饱和像素，验证模糊半径大于图像尺寸及 16 位极值时的结果。
- 实际 `28.4` 天气卡片最高画质/最高抗锯齿截图与优化前比较：CPU、GPU 均为 0 个变化像素、最大通道差 0。图片位于 `obj/regression/artifacts/perf-before-weather-{cpu,gpu}.png` 及 `actual-weather-backend-{2,1}-aa-3.png`。
- 重复提交相同背景 100 次不失效缓存；普通/预翻转 GPU 输入的比较误差要求不超过 1/255；CPU/GPU 往返三次时检查闲置资源已经释放、当前背景仍正确。

## 持续运行与回归

首轮完整测试包含 120 秒持续捕获，结果为 66 通过、1 项静止动画刷新门槛未通过（57 次变化／124 个源帧，要求至少 62 次）。该轮早期同时进行 Debug 编译，不能据此认定为产品回归或认定失败必然由编译造成。停止其他构建后，同一测试按原门槛复测通过：66 次变化／122 个源帧；未放宽门槛。原始记录 `perf-full-soak.txt`、`perf-stationary-recheck.txt` 均保留。

120 秒持续捕获期间保持刷新，471 次抽样观察到背景变化；预热后私有内存 315965440→288235520 字节，句柄 1291→1277，GDI 对象 31→31。此项只能说明本轮两分钟压力场景没有持续增长，不能替代小时级、多屏及不同驱动环境的验证。

拖动两种实时设置均为 42 帧／700 ms，其他静止卡片额外绘制 0 帧；下层卡片更新在外部捕获周期设置为 250 ms 时测得 24 ms 响应。以上是专项场景，不等同于所有交互的输入到显示延迟。

最终在不并行编译的情况下，完整回归 **67 通过、0 失败**，见 `obj/regression/perf-final-full.txt`。两个默认配置均构建成功，构建日志无错误/警告，`git diff --check` 通过。

## 2026-09-26 片元与模糊核优化

在各质量档位的渲染参数、FBO 分辨率、模糊采样和文字栅格化保持不变的前提下，继续减少渲染路径的无效工作：

- 玻璃对象绘制启用屏幕空间 scissor，只覆盖对象及其连接对象的联合外接矩形，并保留 1.5 个逻辑像素的抗锯齿边界。原先每个对象都让全屏四边形执行 SDF、连接融合和折射；现在对象外的片元在光栅化阶段直接丢弃，输出像素不变。
- 模糊核的高斯权重和双线性采样偏移按模糊半径、渲染缩放和采样步长缓存。实时背景更新只复用同一组权重，不再每帧重复计算 `exp()` 和临时 `QVector`；改变相关设置时才重建。

定向回归（圆角抗锯齿、三档模糊强度、最高档无采样纹、最高文字抗锯齿、背景方向复用）7 项全部通过。完整回归 80 项通过、1 项失败；失败为组件库动画捕获采样时序门槛（30/66 与此前同类压力场景的时序波动），其余测试通过。Release 回归工程编译无错误或警告。
