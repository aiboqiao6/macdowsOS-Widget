# 设置窗口主题

`settings-theme.json` 和 `settings.qss` 是内嵌默认主题。布局和自绘控件共用这些参数。

窗口每次创建时，读取 `QStandardPaths::AppConfigLocation/settings-theme.json` 的部分覆盖。
也可以设置环境变量 `MACDOWSOS_SETTINGS_THEME` 指向指定 JSON 文件，便于设计调试。
不需要重新编译。示例：

```json
{
  "sidebarRatio": 0.312,
  "rowPadding": 0.7,
  "fontScale": 1.111111,
  "dark": {
    "canvas": "#1e1e1e",
    "group": "#252525",
    "accent": "#007aff"
  }
}
```

长度以当前窗口字体的 em 为单位；比例和字体倍率无单位。Qt 负责设备像素比，
不再额外乘 DPI。字体变化会重新计算间距、控件宽度、圆角和图标尺寸；窗口缩放时，
侧栏由比例、最小/最大宽度与正文保留宽度共同计算，页面使用滚动布局，底部按钮独立保留。
控件宽度还取决于选项文字的实际字体度量。

颜色使用 Qt 的 `#RRGGBB` 或 `#AARRGGBB` 格式；八位格式的前两位为透明度。
未知字段、类型错误、无效颜色和越界数值不会覆盖默认值，格式错误的文件整体回退。
窗口创建后使用配置快照；修改文件后重新打开设置窗口生效。

自绘仅接管原生 Qt 控件的显示，保留其选择模型、键盘操作和辅助功能。
导航和选择器文字通过项目共用的自研文字绘制入口输出。

设置窗口仅采集侧栏后方的真实画面，包含下层窗口与小组件；拖动时附带移动余量。采集完成后先裁出当前可见侧栏，再补齐壁纸、合成下层小组件并进行三次可分离方框模糊（近似高斯）。
`sidebarBlurRadius` 使用 em 单位，默认 1.1 em；独立的 `sidebarRenderScale` 默认为最低档 60%，同时用于捕获、合成与模糊，不读取小组件的画质或材质设置。
右侧内容使用不透明的 `canvas` 颜色；标题栏使用 `toolbarTop` 到 `toolbarBottom` 的轻微渐变，不应用折射或噪点。
版本信息、软件更新、更新日志和下载操作统一位于“关于”，侧栏不再设置独立的更新入口。
默认窗口为 54 × 45 em，侧栏占宽度的 31.25%；`windowWidth`、`windowHeight` 可覆盖默认尺寸。
标题栏显示胶囊式前进后退控件与页面名称；页面说明移到首个分组中的图标概览。导航按基础设置、组件与关于分段。
前进后退保留当前窗口内的页面访问历史，并支持系统后退和前进快捷键；返回历史页面会清除侧栏搜索，进入新页面会截断后续历史。
侧栏列表未选中时使用主题固定字色：深色主题为 `navigationLight`，浅色主题为 `navigationDark`。选中项使用 `onAccent`（默认白色），与强调色背景配合。背景和悬停均不改变字色，不绘制文字描边。
底部固定保留取消与完成按钮，完成位于右侧。通用页按桌面交互与启动分组。
`dark.sidebar` 和 `light.sidebar` 控制侧栏覆盖色；降低其 alpha 会增加背景可见度。
默认侧栏覆盖色 alpha 为 247/255，约 3% 的实时模糊背景透出。
设置窗口的栅格背板由 Windows DWM 呈现，独立工作线程使用 `DwmFlush` 对齐采集节奏，静止时最高约 30 Hz、拖动时最高约 60 Hz，不读取小组件画质参数。采集结果立即进入合成和后台模糊，完成后交给 Qt 与 DWM 呈现，不再等待下一次采集节拍。
工作线程在两次有效采集节拍之间休眠；远程桌面使 DWM 等待立即返回时也避免空转。最小化和隐藏时停止时钟、清空待处理背景，恢复显示后重新采集。
采样使用异步队列并合并过期请求，不复用旧帧中的局部窗口像素；尚未获得有效像素的区域用桌面壁纸补齐，再合成下层小组件，避免显示面板实色。
标题栏使用 Qt 鼠标拖动，拖动时继续处理刷新与异步回调。拖动采集区域向各方向扩展窗口尺寸的 `sidebarCaptureOverscan`（默认 25%），完整重建扩展区域后按提交时的最新窗口位置裁剪，目标平移不会使整帧失效；尺寸、下层窗口身份/次序和上层遮挡仍会重新验证。
设置面板不绘制外侧边线和内沿高光；红绿灯按钮保留轻微明暗变化。开关采用参考图中的宽胶囊滑块，开启时显示短竖线。

模糊保持原六遍整数算法的逐像素结果，常用半径使用不超过 64 KiB 的归一化查表。后台任务复用临时图像和列累加缓冲，停止变化 250 毫秒后释放缓冲；始终最多保留一个运行任务和一帧待处理输入，队列已满时暂停发起新采集。
颜色在窗口载入主题时解析一次；字体、固定尺寸和概览图标只在内容、主题、字体或屏幕缩放变化时更新。普通窗口缩放只更新变化的宽度约束，不反复应用整页样式。
