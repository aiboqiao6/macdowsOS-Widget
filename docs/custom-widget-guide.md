# 自定义小组件使用指南

通过“小组件工作室”，可以创建便签、时钟、进度卡片，或使用 HTML、CSS、JavaScript 制作带按钮交互的小组件。保存后可从“添加小组件”窗口拖到桌面，并重复添加多个实例。

[返回项目主页](../README.md) · [功能约束与 JSON 文件格式](custom-widgets.md)

## 创建第一个小组件

1. 右键托盘图标，打开 **设置… → 自定义小组件 → 打开小组件工作室…**。
2. 点击顶部 **新建**，选择“便签”“时钟与日期”“目标进度”或“HTML 计数器”模板。
3. 修改组件名称，选择创作模式和尺寸。
4. 在左侧编辑内容，在右侧查看预览；HTML 按钮和脚本可直接在预览中操作。
5. 点击 **保存并添加到桌面**。如果只想先存入组件库，点击 **保存**。
6. 后续可从托盘菜单打开 **添加小组件…**，在“自定义小组件”分区搜索名称，再将卡片拖到桌面。

组件库为空时，“添加小组件”窗口不显示自定义分区。导入或保存第一个组件后，该分区会出现。

## 选择模式和尺寸

| 模式 | 适合的内容 | 编辑方式 |
| --- | --- | --- |
| 低代码 | 便签、提醒、大数字、时钟、日期、手动进度 | 添加内容块并调整属性 |
| HTML | 自定义排版、按钮、计数器及脚本交互 | 分别编辑 HTML、CSS、JavaScript |

切换模式会保留两边的编辑内容，预览和桌面显示当前选中的模式。

| 尺寸 | 占用桌面网格 | 使用建议 |
| --- | --- | --- |
| 小号 | 1×1 | 简短便签或单个数字 |
| 中号 | 2×1 | 时钟、进度或横向信息卡片 |
| 大号 | 2×2 | 较长内容或更多交互控件 |

实际像素尺寸随全局缩放变化。右侧预览会等比例适应面板，并标注桌面尺寸；顶部拖动栏也会占用一部分高度。

## 低代码示例：制作阅读进度卡片

1. 在 **新建** 菜单中选择 **目标进度**，将名称改为“本周阅读”。
2. 选择“文本”内容块，填写“本周阅读目标”。
3. 选择“大数字”内容块，填写“3 / 5 本”，根据预览调整字号和对齐。
4. 选择“进度条”内容块，将标签设为“完成进度”，数值设为 `60`。
5. 展开 **颜色与边距**，调整背景、文字、强调颜色及内边距。
6. 保存并添加到桌面。

这里的进度数值由你手动填写；修改“3 / 5 本”不会自动计算进度百分比。需要自动计算或按钮操作时，可选择 HTML 模式。

可用的内容块如下：

| 内容块 | 用途 |
| --- | --- |
| 文本 | 标题、说明、提醒，支持换行 |
| 大数字 | 突出显示数字或短文本 |
| 时钟 | 自动显示当前时间 |
| 日期 | 自动显示当前日期 |
| 进度条 | 显示手动设置的 0–100 进度 |
| 分隔线 | 分隔不同内容区域 |

内容块从上到下排列，支持添加、复制、删除、上移、下移和拖动排序。选中内容块后，编辑区只显示适用的属性；内容较长时可滚动查看。

## HTML 示例：制作离线计数器

新建一个组件，选择 **HTML** 模式和 **中号** 尺寸。将下面三段内容分别粘贴到对应的编辑标签中，即可在右侧预览使用“完成一次”和“重置”按钮。这个示例不需要开启联网。

### HTML

```html
<main>
  <div class="title">今日专注次数</div>
  <output id="count">0</output>
  <div class="actions">
    <button id="add" type="button">完成一次 +1</button>
    <button id="reset" type="button">重置</button>
  </div>
</main>
```

### CSS

```css
body {
  margin: 0;
  background: #18243b;
  color: #f4f7ff;
  font-family: "Microsoft YaHei", system-ui, sans-serif;
}
main {
  display: flex;
  flex-direction: column;
  gap: 8px;
  padding: 18px;
}
.title { font-size: 14px; }
output { font-size: 40px; font-weight: 700; line-height: 1; }
.actions { display: flex; gap: 8px; flex-wrap: wrap; }
button {
  border: 0;
  border-radius: 10px;
  padding: 8px 12px;
  background: #78aaff;
  color: #101a2c;
  cursor: pointer;
}
#reset { background: #354562; color: #f4f7ff; }
```

### JavaScript

```javascript
let count = 0;
const output = document.getElementById("count");

document.getElementById("add").addEventListener("click", () => {
  output.textContent = String(++count);
});

document.getElementById("reset").addEventListener("click", () => {
  count = 0;
  output.textContent = "0";
});
```

保存后，桌面组件会运行自己的计数器。预览与各桌面实例的运行状态独立，预览中的点击次数不会复制到桌面。保存的是源代码和配置，计数值会在重新加载、保存更新内容或重启后重置。

重命名或调整工作室窗口大小会保留预览交互状态；修改源内容会重新加载预览。右侧 **重载** 可手动重新运行脚本或重试启动预览。

## 在线资源与运行环境

HTML 模式默认关闭 HTTP/HTTPS 资源和数据请求。需要在线图片、字体、样式、脚本或接口数据时，开启 **允许加载在线资源**；接口请求仍须满足浏览器的跨域规则。

资源使用完整的 HTTP/HTTPS 地址或 `data:` URL。组件没有本地资源根目录，类似 `./image.png` 的相对文件路径不能作为本地资源使用。

组件在隔离的 iframe 中运行，支持内联脚本，但没有宿主 API；不支持访问本地文件、弹窗、下载、摄像头权限、嵌套网页、表单提交及 `eval` / 动态函数构造。仅开启联网也不会解除这些限制。

自定义组件使用系统 **Microsoft Edge WebView2 Runtime**，低代码预览也依赖它。缺失时按提示安装 Runtime，并点击“重载”重试。若提示缺少 `WebView2Loader.dll`，请使用完整发布目录启动程序。

## 保存、编辑与多个实例

- **保存**：更新组件库，并同步同一定义的所有桌面实例。
- **保存并添加到桌面**：先保存，再创建一个桌面实例；重复操作可添加多个实例。
- **编辑桌面组件**：双击组件顶部，或右键顶部选择 **编辑此组件…**。
- **移动桌面组件**：拖动组件顶部；内容区域用于按钮、输入和其他交互。
- **创建独立版本**：使用顶部 **更多 → 创建副本**，再编辑副本。

修改尺寸后，已有桌面实例会优先保留位置，发生冲突时寻找空位。如果空间不足，保存会被取消并保留原布局；可释放桌面空间或选择较小尺寸后重试。

切换组件、新建、导入或关闭工作室时，未保存的修改会提示保存、放弃或取消。常用快捷键为 `Ctrl+S` 保存、`Ctrl+Z` 撤销、`Ctrl+Shift+Z` / `Ctrl+Y` 重做。

## 导入、分享与删除

顶部 **导入** 支持 `.json`、`.html`、`.htm` 文件。导入成功后，组件立即加入组件库和“添加小组件”窗口；每次导入都会分配新的组件 ID。

使用 **更多 → 导出 JSON…** 备份或分享组件。JSON 会包含名称、尺寸、配色、内容块、HTML、CSS、JavaScript 和联网选项；导入 HTML 文件适合复用已有网页内容。文件结构及容量限制见 [功能约束与 JSON 文件格式](custom-widgets.md#组件库与导入导出)。

从组件库删除定义会移除添加窗口中的卡片，桌面上已有实例仍保留快照，可重新编辑并保存。桌面菜单中的 **删除此组件** 只移除对应实例。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 添加窗口没有“自定义小组件”分区 | 先在工作室保存或导入一个组件，并清除不匹配的搜索条件。 |
| 内容显示不全 | 调整字号、边距或内容块数量，选择更大尺寸；HTML 内容可使用弹性布局适应可用宽度。 |
| 桌面按钮无法点击 | 检查设置中是否开启了鼠标穿透，并在组件内容区域操作。 |
| 在线图片或接口无法加载 | 开启“允许加载在线资源”，使用完整地址；接口还需要允许浏览器跨域请求。 |
| 重启后计数器归零 | 脚本运行状态不随组件定义保存；示例计数器每次重新加载都会从零开始。 |
| 保存或添加提示桌面空间不足 | 释放网格空位或选择较小尺寸。首次添加失败时，已保存的定义仍在组件库。 |
| 预览提示引擎或 Loader 缺失 | 安装 WebView2 Runtime，确认程序目录包含 `WebView2Loader.dll`，然后重载预览。 |
