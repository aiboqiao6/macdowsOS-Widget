# 小组件工作室

## 使用流程

1. 托盘右键选择“设置…”，在“自定义小组件”一栏点击“打开小组件工作室…”。工作室关闭后回到设置，尚未提交的设置会保留。
2. 顶部“新建”下拉菜单选择便签、时钟与日期、目标进度或 HTML 计数器。顶部组件列表可切换已保存的小组件。
3. 输入名称、选择创作模式和尺寸，在左侧编辑、右侧预览。底部“撤销 / 重做”恢复内容和内容块操作。
4. 底部“保存”保存到组件库并刷新“添加小组件”窗口的“自定义小组件”独立分区；可以按名称搜索、将卡片拖到桌面添加。“保存并添加到桌面”同时创建一个桌面实例。重复添加可创建多个实例。桌面空位不足时保留组件库内容并提示。没有自定义组件时，不显示自定义分类与分区。
5. 拖动桌面组件的顶部移动；双击顶部或右键顶部“编辑此组件…”再次编辑。保存后，相同组件的所有桌面实例同步更新。尺寸变更优先保留原位置，冲突时寻找空位；无法放置时取消保存并保留原布局。

Ctrl+S 保存。切换组件、新建、导入、关闭或按 Esc 时，有未保存的修改会提示保存、放弃或取消。

## 低代码模式

内容块从上到下排列，支持添加、复制、删除、上移、下移，也可拖动排序。选中内容块后只显示适用的属性：文本可直接输入，时钟、日期自动更新，进度条提供 0–100 数值，分隔线无需设置。展开“颜色与边距”可调整背景、文字、强调颜色和内边距。内容超过可见区域时可滚动。

三档尺寸与现有桌面网格、全局缩放共用同一套尺寸规则：小号 1×1、中号 2×1、大号 2×2。顶部拖动栏占用少量高度；右侧显示桌面实际尺寸，预览自动等比例适应面板。重命名、调整窗口大小不会重置预览的交互状态；修改源内容才会重新加载。“重载”可重置交互或重新启动预览引擎。

## HTML 模式

可直接粘贴 HTML 片段，或导入 `.html` / `.htm` 完整文档；CSS 与 JavaScript 编辑区的内容会一起加载。切换模式会保留两边的编辑内容。预览与桌面使用相同的 WebView2 渲染，包含真实按钮交互和脚本执行。

组件运行在隔离的 iframe 中，没有宿主 API，不能读取工作室页面、打开弹窗、跳转主窗口、下载文件或申请摄像头等权限。默认允许内联脚本、样式和 data URL 资源，关闭 HTTP/HTTPS 资源及数据请求。HTML 模式中开启“允许加载在线资源”后，可加载在线图片、字体、脚本和样式，并请求 HTTP/HTTPS 数据；请求仍受浏览器跨域规则约束。嵌套网页和表单提交不受支持。

相对文件路径没有本地资源根目录。图片等资源应改为绝对 HTTP/HTTPS URL 或 data URL。脚本不支持 eval / 动态函数构造，依赖此类行为的第三方库需调整。脚本运行时状态在刷新或重启后重置，保存的是源代码与配置。

系统需要 Microsoft Edge WebView2 Runtime；缺失时预览会显示明确提示。源码附带官方 x64 Loader，Visual Studio 和回归测试构建均自动复制到程序目录。发布时保留整个输出目录。

## 组件库与导入导出

组件库在应用配置目录的 `custom-widgets.json`，桌面布局和组件快照保存在同目录 `widgets.json`。使用临时文件原子替换。损坏的组件库不会被自动覆盖，保存时会提示错误。

JSON 导出格式：

```json
{
  "format": "macdows-widget",
  "version": 1,
  "definition": {
    "id": "fbc3eb8a-1441-4a19-bf66-fd9cd7053e24",
    "name": "欢迎卡片",
    "mode": "html",
    "variant": 1,
    "blocks": [],
    "html": "<h1>你好</h1>",
    "css": "body { color: white; background: #18243b; padding: 24px; }",
    "javascript": "",
    "allowNetwork": false
  }
}
```

顶部“导入”读取 JSON / HTML 文件，成功后立即加入组件库与添加窗口；导入会分配新的组件 ID，避免覆盖已有组件。顶部“更多 → 导出 JSON”将当前组件的名称、尺寸、配色、内容块、HTML、CSS、JavaScript 与联网选项一起导出，便于备份或分享。“更多”也提供创建副本与从组件库删除。删除会同步移除添加窗口的卡片，但不会删除桌面现有实例，实例的快照仍可恢复，右键编辑后可重新保存。桌面右键“删除此组件”只删除该实例，现有的“至少保留一个托盘管理者”规则继续生效。

添加窗口中的自定义卡片显示名称、创作模式和尺寸；完整交互预览位于工作室右侧。图库不会运行自定义脚本或发起自定义网络请求。

单个组件及导入文件上限 1 MB，最多 40 个内容块，名称最多 80 字，组件库最多 200 个组件及 32 MB。HTML 编码后还会检查 WebView2 的页面大小限制；超过限制会显示错误。
