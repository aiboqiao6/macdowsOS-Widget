# 统一文字渲染

应用界面、图库、向导、设置、菜单、编辑器和桌面卡片统一以资源中的 `pingfang0.ttf` 为首选字体。字体内部族名由 `QFontDatabase` 读取；未覆盖的文字由 Qt 整形器选择可用的补充字形，避免显示空白。

`AppFonts` 管理注册、应用字体和兼容设置。`ClearTypeText` 是保留的历史模块名，现在实现 macOS 风格的灰阶文字：

- Qt 提供文字整形、字距、双向排版和矢量字形轮廓。
- 项目自己进行轮廓扫描、非零绕向填充、横向面积积分和纵向 16 次采样，生成 8 位灰阶覆盖率。
- 使用活动边表及轮廓、覆盖率、着色图像缓存。对应容量上限分别为 2、8、4 MiB，计入文字键的大小；超大项目直接绘制，不存入缓存。
- CPU 与 OpenGL 使用同一份覆盖率和预乘透明度混合。GL 纹理为单通道，文字每次只需一遍绘制；每个上下文缓存上限为 4 MiB。
- 保留分数字号，按最终设备分辨率扫描文字，独立于玻璃背景的渲染比例。适配层直接读取当前画笔状态，避免控件重定向或 `save/restore` 导致重复缩放与旧字重。旋转、非等比缩放、渐变画笔和超长文字采用裁剪后的分块扫描，不回退到系统文字位图。

`AppText::PaintDevice` 转发几何绘制并接管标准控件产生的文字操作。`AppText::Control` 为标签和单行编辑框提供绘制重定向；数字、日期控件使用相同的单行编辑框。编辑器、富文本浏览器及列表在文字视口中使用适配设备。选区、光标、滚动、撤销、输入法和无障碍仍由原控件管理。普通 `QScrollArea` 的内容容器不替换。

应用默认开启 macOS 风格灰阶抗锯齿，启动时将旧配置中的关闭状态和其他档位统一迁移为开启。设置页已移除“字体抗锯齿”和“文字显示”两项。底层保留旧档位兼容接口供渲染回归验证，设置界面使用固定灰阶质量。

## HTML 边界

自定义 HTML 由独立的 WebView2 进程运行。应用通过本地 WebResourceRequested 响应提供同一份 PingFang 字体，CSS 使用该字体，禁用联网时同样可用。`macdows-fonts.invalid` 仅是应用拦截的资源地址，无需 DNS 或外部服务器。

内置字体的转换文件存在 `maxp.maxZones=0` 和截断的纵向度量，浏览器 OTS 会拒绝原文件。浏览器响应在内存中修正该字段、移除损坏的可选纵向度量表并重算校验和。原资源不修改；测试逐个比较中英文样本的字形编号、轮廓和横向字距，验证修复前后一致。

WebView2 内的网页字形最终仍由浏览器栅格化，不经过 C++ 扫描器。Windows 系统窗口标题栏、系统文件选择器和系统托盘提示也由操作系统绘制。上述外部表面不应宣称使用了自研栅格器。

验证用例与运行方式见 [tests/README.md](../tests/README.md)。
